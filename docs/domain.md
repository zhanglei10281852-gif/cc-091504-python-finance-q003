# 领域说明

股权激励由授予协议、服务期间、绩效条件和结算方式共同决定。停薪休假、离职、黑窗期与税务身份会改变批次的可归属数量及处理时间。人事、薪资和证券管理岗位分别维护不同事实，结算结果需要关联当时有效的协议、价格、汇率和审批记录。

`reference/domain.json` 保存可公开的示例枚举与精度约定。正式业务记录应使用稳定标识，并区分业务发生时间、系统接收时间和记录版本。

## 批次状态机

```
PENDING 待满足 ──条件满足──▶ RELEASABLE 可执行 ──结算──▶ SETTLED 已结算
     │                            ▲   │
     │                            │   │ 黑窗期进入/解除
     │                            │   ▼
     │                            └── LOCKED 锁定
     └──失效条件（绩效未达标 / 离职 / 窗口届满 / 修订移除）──▶ FORFEITED 失效
```

- 待满足批次始终按最新资料（休假、绩效、协议版本）重算；
- 已归属批次（锁定/可执行）的数量与归属日冻结，仅随黑窗期切换状态；
- 已结算批次封存协议版本、价格、汇率、税额与到账构成，不得倒改。

## 确定性约定

- 时间：归属日与截止日按协议时区自然日界定，内部统一换算 UTC 比较；
- 数量：Decimal；金额两位小数（ROUND_HALF_UP）；交付股数向下取整，不足一股现金补偿；抵税股数向上取整，多抵返还；
- 汇率：1 单位计价货币 = rate 单位计税货币，按结算日当日汇率；
- 幂等：结算执行携带幂等键，重放返回原结果，并发下不会重复扣股或付款；
- 版本：协议修订只追加版本且生效日不得早于修订当日；历史版本永不改写。

## 岗位分工

| 岗位 | 负责数据 |
| --- | --- |
| 人事 HR | 服务期间、休假、离职事实 |
| 薪资 PAYROLL | 税务身份、预扣口径、现金补缴 |
| 证券管理 STOCK_ADMIN | 授予、市场价格、黑窗期、交割 |

三方在结算批次上分别确认；退回时保留原意见与差异，修正后重新提交，历史记录不清除。
