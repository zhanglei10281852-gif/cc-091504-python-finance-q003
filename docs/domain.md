# 领域说明

股权激励由授予协议、服务期间、绩效条件和结算方式共同决定。停薪休假、离职、黑窗期与
税务身份会改变批次的可归属数量及处理时间。人事、薪资和证券管理岗位分别维护不同事实,
结算结果需要关联当时有效的协议、价格、汇率和审批记录。

`reference/domain.json` 保存可公开的示例枚举与精度约定。正式业务记录应使用稳定标识,
并区分业务发生时间、系统接收时间和记录版本。

## 批次状态机

```
PENDING 待满足 ──条件满足──> LOCKED 锁定 ──审批齐全且非黑窗──> EXERCISABLE 可执行 ──结算成功──> SETTLED 已结算
    │                            │                                  │
    └──离职作废/绩效未达标──────> LAPSED 失效 <──行权窗口届满────────┘
                                 ^__________ 黑窗或审批失效回退 __________|
```

`SETTLED` 与 `LAPSED` 为终态。已结算批次不得倒改;协议修订只能追加向后生效的新版本,
批次归属(进入 LOCKED)时锁定管辖协议版本。

## 关键规则

- **休假暂停计时**:实际归属日 = 基准归属日 + 此前累计停薪休假天数,迭代至不动点;
  休假截断到服务期间内,离职日后的休假不计。
- **部分达标**:达成率 = 实际值 / 目标值(4 位小数向下),按阶梯曲线取满足的最高档;
  归属比例为零的批次失效。
- **离职政策**(默认,可注入):主动离职未归属作废、已归属 90 天行权窗口;非自愿加速 50%、
  窗口 180 天;过失解除全部作废;退休与身故伤残 100% 加速、窗口 365 天。
- **跨时区截止点**:截止日按授予时区日末换算 UTC;落在黑窗内顺延至黑窗结束。
- **结算**:应纳税所得额 = 归属股数 × 归属日市价(as-of 快照);按税务身份累进预扣;
  币种不同时用同一汇率快照换算。净股交付与卖股缴税均扣"覆盖税额的最小整股",
  差额现金找零;不足一股部分按市价折现金补偿;税额超过交付价值时员工现金补缴。
- **审批**:三岗位各自对当前数据快照确认;数据变更使对应确认失效;退回必须附意见,
  退回记录永久保留,重新确认自动携带与退回快照的字段级差异。
- **并发与幂等**:结算以幂等键去重,状态检查与台账扣减在同一临界区;网关失败只产生
  失败回执,不入台账、不改批次状态,修正后换新幂等键重试。
